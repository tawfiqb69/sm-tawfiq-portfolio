# ST. — SM Tawfiq Portfolio

A responsive Next.js portfolio using the agreed Dark Creative design:
- Deep Black `#0A0A0A`
- Neon Lime `#A3E635`
- Soft White `#E5E7EB`
- Muted Gray `#9CA3AF`
- Inter font
- `ST.` brand mark

## Run locally

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open http://localhost:3000

## Before publishing

Update `lib/site-data.js` with your real contact email, LinkedIn URL, and verified repository/live-demo links. Replace the project preview placeholders with real screenshots and add your portrait as `public/images/tawfiq.jpg` (then update the `portraitSrc` value in `lib/site-data.js`).

The contact form uses `mailto:` as planned. It opens the visitor's default email app with the form details prefilled; it does not send email automatically.

## Deploy to Vercel

1. Push this folder to a public GitHub repository.
2. Import the repository at https://vercel.com/new.
3. Deploy with the default Next.js settings.
4. Choose an available Vercel project/domain name.

The preferred `smtawfiq.vercel.app` domain is only an example until availability is confirmed.
